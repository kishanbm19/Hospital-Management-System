MediCore HMS 🏥

MediCore HMS is a full-stack Hospital Management System built using Django, React, and MySQL.

The system helps manage:

Hospitals
Departments
Doctors
Patients
Appointments
Blood Banks
Donors
Bed Availability
🚀 Tech Stack
React.js
Django REST Framework
MySQL
✨ Features
Appointment Management
Blood Bank Tracking
Hospital Dashboard
Bed Availability Monitoring
Responsive UI
📌 Project Type

DBMS Mini Project | Full Stack Web Application
